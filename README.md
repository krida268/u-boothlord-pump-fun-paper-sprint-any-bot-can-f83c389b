An early-catch paper-trading bot for pump.fun: it buys each new coin once, on the first batch its 1%-of-real-reserve buy cap reaches 0.02 SOL and its price is still within 1.20x of creation, then sells the whole position on the first of a 1.20x take-profit, a 0.97x stop, a trailing stop once armed at 1.50x, or a 200-slot time limit while flat. One entry per coin, no pyramiding, no re-entry — every exit frees a slot for a fresh coin.

## Run it

```sh
node main.ts
```
